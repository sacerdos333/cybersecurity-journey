# Home Cybersecurity Lab

## Primary Workstation

My primary cybersecurity lab environment is a custom Windows desktop workstation that I use for hands-on networking, cybersecurity, data science, virtualization, and GitHub portfolio development.

### Hardware

- Intel Core i7-13700F (13th Generation)
- 32 GB DDR5 RAM
- NVIDIA GeForce RTX 4060 Ti (16 GB)
- Approximately 2.7 TB Storage
- 64-bit Windows 11 Home (Version 25H2)

## Networking

My workstation includes both wired Ethernet and modern wireless networking capabilities.

### Ethernet

- 2.5 Gigabit Ethernet Adapter

### Wireless

- Intel Wi-Fi 6E AX211
- Supports:
  - Wi-Fi 6 (802.11ax)
  - 2.4 GHz
  - 5 GHz
  - 6 GHz
  - WPA2
  - WPA3

## Purpose

This workstation serves as my primary cybersecurity learning environment where I perform:

- Windows networking labs
- PowerShell exercises
- Wireshark analysis
- GitHub documentation
- Virtualization labs
- Future SOC investigations
- Security tool development
